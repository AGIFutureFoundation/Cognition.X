Regenerate everything

The whole platform rebuilds from one CSV:

python3 tools/generate_pack.py spec.json > out.csv python3 tools/normalize_blocks.py python3 tools/validate_blocks.py # CI runs this python3 tools/build_flow_hub.py python3 tools/build_louisiana.py python3 tools/build_education_os.py python3 tools/build_trades.py python3 tools/build_states.py python3 tools/build_platform.py # this page python3 tools/evidence_triage.py # the loop's return path

The honesty stances

  • Every block ends in a transfer check on real material.
  • Simulation ≠ certification — carried verbatim, everywhere.
  • No union local numbers — the regional council is the front door.
  • Access profiles are chosen supports, never diagnoses.
  • The capability is the constant; the format is the variable.
  • Nothing leaves any page on its own — export boxes are the only exits.
  • A signature proves integrity and key possession; identity is confirmed out-of-band.
  • Evidence proposes; the board disposes — ids are never rewritten, only superseded.
