Eight agents, one swarm

Rule-based agents run the session machinery so your attention stays on the block in front of you. The four tutors operate as a swarm: they watch one shared blackboard of your session, each proposes an intervention, and priority arbitration lets exactly one act per move — so you get the right nudge, never a chorus.     Pack Studio · educator authoring

    Author a pack

    Write a pack spec the pipeline can build: tracks of ten themes, each theme with a description and a transfer check on real material. The Studio validates as the generator would, previews the block count, and exports the spec JSON. Your draft stays in this browser.

    Submitting — GitHub is the review pipeline

    1. Save the exported JSON as data/pack_specs/<your-pack>.json in a fork of the repository.
    2. Run python3 tools/generate_pack.py → normalize_blocks.py → validate_blocks.py (or let CI do it on your pull request).
    3. Open the pull request. The curriculum review board (see docs/GOVERNANCE.md) reviews for accuracy, safety, honest transfer checks and respectful terminology before merge.

    This offline file can't open the pull request for you — the spec export plus the repository is the whole pipeline, and the review board is the quality gate.
