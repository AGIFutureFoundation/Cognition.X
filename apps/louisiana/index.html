    Machine learners · every module teaches twice

    Agents and robots in the loop

    Every Cognition.X block ends in a human doing something real. Done with consent and care, those interactions are also the highest-grade training signal a learning agent or robot can get — and the flow-state engine that paces a human learner paces a machine curriculum just as well.

    The learning loop

    One block, two learners: the human earns the credential; the machine, with consent, learns from how it was done.

    What one module teaches a machine

    The machine-learnable signals inside every transfer check.

    DemonstrationThe human's step order, grip, phrasing and corrections on real material — imitation-learning gold.
    CorrectionWhere a learner or assessor says "not like that" — the negative examples models rarely get.
    PacingHow long each band actually takes a human — the ground truth for curriculum difficulty.
    BoundariesThe steps humans refuse or escalate — safety limits learned from practice, not just rules.
    Flow telemetryBreezed / in-flow / struggled outcomes on the skill–challenge plane — the reward shape itself.

    Flow state for machines

    The same channel that paces a person paces an agent.

    Curriculum learning is the flow channel by another name: serve the machine tasks just above its demonstrated competence, ease off on failure, advance on mastery. The Flow Hub's engine — challenge within skill −0.6 … +1.1 — is the scheduler for both learners.

    A robot trained on module traces climbs the same ladder a learner does: Explorer (observe & classify) → Builder (assist on subtasks) → Practitioner (perform under supervision) → Lead (teach back, flag exceptions).

    Data principles — non-negotiable

    Local firstTraces are recorded and stored only in the learner's browser; nothing on this page transmits anywhere.
    Opt-in exportData reaches any training pipeline only when the learner exports it themselves, per session, eyes open.
    Anonymized by defaultExports carry skill signals, never identity; the ledger and the trace are separable.
    The learner is paid in capabilityAny machine trained on community traces must serve back into the same community's classrooms and Trade Halls.
